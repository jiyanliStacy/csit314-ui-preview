# CSIT314 Interior Design Platform: UI preview

Live preview: **https://jiyanlistacy.github.io/csit314-ui-preview/**

These are the real pages of the app, rendered with the seeded demo data and saved as plain HTML, so they open in a
browser without Python or a database. It contains no source code.

- Links between the saved pages work, and so do the hover effects and animations.
- Forms do not save anything here. The "Outcome screens" on the start page show what the app returns after a form is sent.
- All names and emails are fake demo data from the project's seed script.
- Room photos: [Pexels](https://www.pexels.com/license/). Fonts: Fraunces and Inter (Google Fonts, SIL Open Font License).
